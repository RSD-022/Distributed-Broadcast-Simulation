# Distributed-Broadcast-Simulation
Design and Experimental Evaluation of Diffuse-v3 Broadcasting on Synthetic and Real-World Network Topologies Using OMNeT++


##Problem statement
In a distributed system, information must be disseminated from an initiating process to other processes through message-passing communication.
The challenge is that different network structures and communication conditions can substantially affect the behavior of a broadcasting protocol.
A protocol that behaves efficiently on a small tree may generate different communication overhead on a densely connected network.
Our project will investigate this behavior systematically.

So our question here is **How do network topology, network size, communication delay, and node failures affect the correctness and performance of the Diffuse-v3 distributed broadcasting algorithm?**

##hypotheses to test
H1 For a fixed number of nodes, changing network connectivity can change the number of messages generated by Diffuse-v3.
H2 Increasing communication delay increases broadcast dissemination time when other conditions remain unchanged.
H3 The position of the initiator influences dissemination time, particularly in networks with long paths.
H4 Node failures and message loss can reduce the proportion of reachable nodes receiving the broadcast.
H1 The benefits of using information contained in Diffuse-v3 messages may involve a trade-off between transmission count and message size.
